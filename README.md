## Portable Mode Wrapper

A simple portable mode wrapper that launches Zed Editor in portable mode. File structure should look like this:

```
 │
 ├── app/                  # Must contain zed.exe
 ├── data/                 # Where data will be stored
 └── zed-launcher.exe      # Launcher itself
```

You can get unofficial zip builds from <a href="https://github.com/deevus/zed-windows-builds">https://github.com/deevus/zed-windows-builds</a> or extract it from the official installer.
